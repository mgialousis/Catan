# Reviewed presentation fixes — release verification

Verified 2026-09-21 (Europe/Zurich). Application commit:
`e8744ee942037c40295e9f318d757fc7c6720cbd`.

## Shipped changes

- Opening placements use their actual engine command names for pacing, including
  the final setup road. That road no longer triggers a camera close-up.
- Zero-payout rolls finish after the dice hold. Shared timing fixtures check the
  server waits beyond the client presentation for zero, one and three cards.
- Rapid trades cannot evict an unfinished payout from pacing history. The runner
  scans indexed history pages within the maximum possible presentation window;
  there is no migration or new persistent pacing write.
- The board fits below measured notices/countdowns and above the resource dock.
  Very large text and long notices retain a usable, scrollable board. Dice also
  fit short landscape boards, and the header exposes the total to screen readers.
